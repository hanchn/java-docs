在 Java 中，**运算符（Operator）**是对数据进行计算或操作的符号。熟练掌握各种运算符的用法和特性，对我们编写高效且正确的程序十分关键。下面将运算符进行分类并逐一介绍其含义与使用示例。

---

## 一、算术运算符（Arithmetic Operators）

| 运算符 | 含义       | 示例           | 结果           |
|--------|------------|----------------|----------------|
| `+`    | 加法       | `3 + 2`        | `5`            |
| `-`    | 减法       | `5 - 2`        | `3`            |
| `*`    | 乘法       | `3 * 2`        | `6`            |
| `/`    | 除法       | `7 / 2`        | `3`（整数除法）<br>`3.5`（浮点数除法） |
| `%`    | 取模（余数）| `7 % 2`       | `1`            |

- **注意**：当操作数都是 **整数**（int、long 等）时，`/` 运算符执行**整数除法**，会**舍弃小数部分**；若有任意一方为**浮点数**（float、double），则执行浮点数运算。
- **示例**：
  ```java
  int a = 7;
  int b = 2;
  System.out.println(a / b);     // 3（整数除法）
  System.out.println(a / 2.0);   // 3.5（浮点除法）
  System.out.println(a % b);     // 1
  ```

---

## 二、关系运算符（Relational Operators）

| 运算符 | 含义           | 示例         | 结果（布尔） |
|--------|----------------|--------------|--------------|
| `==`   | 等于           | `3 == 2`     | `false`      |
| `!=`   | 不等于         | `3 != 2`     | `true`       |
| `>`    | 大于           | `3 > 2`      | `true`       |
| `<`    | 小于           | `3 < 2`      | `false`      |
| `>=`   | 大于或等于     | `3 >= 2`     | `true`       |
| `<=`   | 小于或等于     | `3 <= 2`     | `false`      |

- **返回值**：关系运算的结果是 `true` 或 `false`，即布尔类型。
- **常用场景**：判断两个值之间的大小关系，在 `if`、`while` 等条件语句中经常用到。

---

## 三、逻辑运算符（Logical Operators）

| 运算符 | 含义                 | 示例              | 结果      |
|--------|----------------------|-------------------|-----------|
| `&&`   | 逻辑与（短路与）     | `(3 > 2) && (2 > 1)` | `true`  |
| <code>\|\|</code> | 逻辑或（短路或） | `(3 > 2) \|\| (2 < 1)` | `true`  |
| `!`    | 逻辑非               | `!(3 > 2)`        | `false`   |

- **短路特性**：
   - `&&`（短路与）：若左侧表达式为 `false`，则**不会**继续计算右侧表达式。
   - <code>\|\|</code>（短路或）：若左侧表达式为 `true`，则**不会**继续计算右侧表达式。
- **示例**：
  ```java
  boolean x = (3 > 2) && (2 > 1);   // true && true => true
  boolean y = (3 > 2) || (2 < 1);   // true || false => true
  boolean z = !(2 == 2);           // !(true) => false
  ```

> **拓展**：Java 中还有**按位与** `&`、**按位或** <code>\|</code>，如果用于布尔运算，也可看做逻辑运算符，但它们**不具有短路特性**。同理 <code>&&</code> 与 `&` 在布尔表达式的意义有所不同。

---

## 四、位运算符（Bitwise Operators）

位运算符是对**整数类型**（byte, short, int, long）的二进制表示进行操作。

| 运算符 | 含义                | 示例        | 说明                                    |
|--------|---------------------|------------|-----------------------------------------|
| `&`    | 按位与（AND）       | `6 & 3`    | `6` 的二进制 `110` <br>`3` 的二进制 `011` <br>`110 & 011 = 010`（即 `2`） |
| <code>\|</code>   | 按位或（OR）        | `6 \| 3`   | `110 \| 011 = 111`（即 `7`）                |
| `^`    | 按位异或（XOR）     | `6 ^ 3`    | `110 ^ 011 = 101`（即 `5`）                |
| `~`    | 按位取反（NOT）     | `~6`       | `6` 的二进制 `0000 0110` <br>`~6` => `1111 1001`（对应有符号整型 `-7`）|
| `<<`   | 左移                | `3 << 2`   | `3` 的二进制 `011` 左移 2 位 => `1100`（即 `12`）|
| `>>`   | 右移（带符号右移）   | `12 >> 2`  | `12` 的二进制 `1100` 右移 2 位 => `0011`（即 `3`）  |
| `>>>`  | 无符号右移（逻辑右移） | `-1 >>> 1` | 与 `>>` 类似，但高位补 `0`，常见用于无符号数运算。 |

- **注意**：
   - `>>` 保留**符号位**，如果是负数右移高位补 `1`，正数补 `0`；
   - `>>>` 不管正负，高位都补 `0`。
- **示例**：
  ```java
  int a = 6;          // (binary:  110)
  int b = 3;          // (binary:  011)
  System.out.println(a & b);  // 2  (binary: 010)
  System.out.println(a | b);  // 7  (binary: 111)
  System.out.println(a ^ b);  // 5  (binary: 101)
  System.out.println(~a);     // -7
  System.out.println(12 >> 2);// 3  (12的二进制 1100 -> 0011)
  ```

## 五、三目运算符（三元运算符）

**格式**：`boolean 表达式 ? 表达式1 : 表达式2`

- 当 `boolean 表达式` 为 `true` 时，执行并返回 **`表达式1`** 的值；否则执行并返回 **`表达式2`** 的值。
- 常用于简化 `if-else` 结构。
- **示例**：
  ```java
  int score = 85;
  String result = (score >= 60) ? "及格" : "不及格";
  System.out.println(result); // 输出：及格
  ```

## 六、赋值运算符（Assignment Operators）

### 6.1 基本赋值运算符

- `=`：将右侧值赋给左侧变量。
  ```java
  int x;
  x = 10;
  ```

### 6.2 扩展赋值运算符

| 运算符  | 等价写法     | 示例         |
|---------|--------------|--------------|
| `+=`    | `a = a + b`  | `a += b;`    |
| `-=`    | `a = a - b`  | `a -= b;`    |
| `*=`    | `a = a * b`  | `a *= b;`    |
| `/=`    | `a = a / b`  | `a /= b;`    |
| `%=`    | `a = a % b`  | `a %= b;`    |
| `<<=`   | `a = a << b` | `a <<= b;`   |
| `>>=`   | `a = a >> b` | `a >>= b;`   |
| `>>>=`  | `a = a >>> b`| `a >>>= b;`  |
| `&=`    | `a = a & b`  | `a &= b;`    |
| <code>\|=</code> | `a = a \| b`  | <code>a \|= b;</code>   |
| `^=`    | `a = a ^ b`  | `a ^= b;`    |

- **示例**：
  ```java
  int a = 5;  // 二进制 0101
  a += 3;     // 等价于 a = a + 3 => 8 (0101 + 0011 = 1000)
  a <<= 2;    // 等价于 a = a << 2 => 32 (1000 << 2 = 100000)
  System.out.println(a);  // 32
  ```

> **注意**：在执行 `a += b` 这样的操作时，会**自动进行类型转换**（隐式的），例如 `short a = 1; a += 1;` 是合法的；若写成 `a = a + 1;` 则可能需要强制类型转换。

## 七、综合示例

```java
public class OperatorDemo {
    public static void main(String[] args) {
        // 1. 算术运算
        int a = 7, b = 2;
        System.out.println("a + b = " + (a + b));    // 9
        System.out.println("a - b = " + (a - b));    // 5
        System.out.println("a * b = " + (a * b));    // 14
        System.out.println("a / b = " + (a / b));    // 3（整数除法）
        System.out.println("a % b = " + (a % b));    // 1

        // 2. 关系运算
        boolean isGreater = (a > b);
        System.out.println("a > b ? " + isGreater);  // true

        // 3. 逻辑运算
        boolean c = false;
        System.out.println("(a > b) && c = " + ((a > b) && c)); // false（短路于 c）
        System.out.println("(a > b) || c = " + ((a > b) || c)); // true

        // 4. 位运算
        int x = 6;  // (binary: 0110)
        int y = 3;  // (binary: 0011)
        System.out.println("x & y = " + (x & y));  // 2 (binary: 0010)
        System.out.println("x | y = " + (x | y));  // 7 (binary: 0111)
        System.out.println("x ^ y = " + (x ^ y));  // 5 (binary: 0101)
        System.out.println("~x = " + (~x));        // -7
        
        // 5. 三元运算符
        int score = 85;
        String result = (score >= 60) ? "及格" : "不及格";
        System.out.println("考试结果：" + result);

        // 6. 赋值运算符
        int d = 10;
        d += 5;  // 等价于 d = d + 5
        System.out.println("d = " + d);  // 15
        d <<= 1; // 等价于 d = d << 1 => 15 << 1 = 30
        System.out.println("d = " + d);  // 30
    }
}
```

## 八、总结

1. **算术运算符**：对数值进行加减乘除和求余运算，注意整数除法和浮点数除法的区别。
2. **关系运算符**：比较两个值大小或是否相等，返回布尔值。
3. **逻辑运算符**：多用于条件判断与复合逻辑表达式；`&&` 与 <code>\|\|</code> 具有短路特性。
4. **位运算符**：直接对整数的二进制位进行操作，常用于低层次的性能优化、图像处理、加密算法等场景。
5. **三目运算符**：简化 `if-else`，根据布尔表达式决定返回值。
6. **赋值运算符**：`=` 完成最基本的赋值操作，`+=` 等扩展运算符可简化操作并伴随类型转换。

熟练掌握这些运算符及其用法，有助于我们编写逻辑紧凑、表达简洁的代码。在使用过程中，要特别留意运算符的**优先级**、**短路特性**以及**整数除法的差异**等细节，以避免出现意料之外的结果。

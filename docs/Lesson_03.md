在 Java 中，数据类型（Data Types）可以分为**基本数据类型**（Primitive Types）和**引用数据类型**（Reference Types）。理解和合理运用这两大类数据类型对于编写高质量的 Java 程序至关重要。本篇将对 Java 的数据类型进行系统介绍，并重点讲解包装类（Wrapper Class）的作用和使用。

---

## 一、基本数据类型（Primitive Types）

Java 共有 **8 种**基本数据类型，分别是 **四类整型**、**两类浮点型**、**一个字符型**以及**一个布尔型**。它们都是**值类型**，在栈中直接存储变量的值，不包含任何对象属性或方法。

### 1.1 整数类型

1. **byte**
   - **长度**：8 位（1 字节）
   - **取值范围**：\[-128, 127\]
   - **默认值**：0（在成员变量中）
   - **常用场景**：节省空间，用于大型数组或者在网络传输和文件操作中常见的二进制数据处理。
   - **示例**：
     ```java
     byte b = 100;
     ```

2. **short**
   - **长度**：16 位（2 字节）
   - **取值范围**：\[-32768, 32767\]
   - **默认值**：0
   - **常用场景**：较少使用，一般在需要更精确地节省内存时才考虑。
   - **示例**：
     ```java
     short s = 1000;
     ```

3. **int**
   - **长度**：32 位（4 字节）
   - **取值范围**：\[-2^31, 2^31 - 1\]，即约 \[-2,147,483,648, 2,147,483,647\]
   - **默认值**：0
   - **常用场景**：最常见的整型类型，适用于大部分整数运算场景。
   - **示例**：
     ```java
     int i = 100000;
     ```

4. **long**
   - **长度**：64 位（8 字节）
   - **取值范围**：\[-2^63, 2^63 - 1\]
   - **默认值**：0L
   - **常用场景**：需要表示更大范围的整数时，如时间戳（毫秒级）等。
   - **注意**：在给 long 赋值时，整数常量最好在后面加上 `L`（或小写 `l`），以防编译器将其视为 int 处理。
   - **示例**：
     ```java
     long phoneNumber = 12345678900L;
     ```

### 1.2 浮点数类型

1. **float**
   - **长度**：32 位（4 字节）
   - **取值范围**：约 \(\pm 3.4 \times 10^{-38}\) 到 \(\pm 3.4 \times 10^{38}\)
   - **默认值**：0.0f
   - **精度**：单精度浮点数，大约 7 位有效数字。
   - **注意**：浮点字面量默认为 double，给 float 赋值时需加 `f` 或 `F`。
   - **示例**：
     ```java
     float f = 3.14f;
     ```

2. **double**
   - **长度**：64 位（8 字节）
   - **取值范围**：约 \(\pm 1.7 \times 10^{-308}\) 到 \(\pm 1.7 \times 10^{308}\)
   - **默认值**：0.0d（可以省略 `d`）
   - **精度**：双精度浮点数，大约 15~16 位有效数字。
   - **常用场景**：大多数浮点计算场景。
   - **示例**：
     ```java
     double d = 3.141592653589793;
     ```

> **注意：** 浮点数运算会有**精度问题**，在需要精准数值（如货币计算）时通常使用 `BigDecimal`。

### 1.3 字符类型

1. **char**
   - **长度**：16 位（2 字节）
   - **取值范围**：\u0000 (0) ~ \uffff (65535)（Unicode 范围）
   - **默认值**：`\u0000`
   - **常用场景**：表示单个 Unicode 字符（包括中日韩字符等）。
   - **示例**：
     ```java
     char c = 'A';
     char ch = '中';
     ```

### 1.4 布尔类型

1. **boolean**
   - **取值**：`true` 或 `false`
   - **长度**：在 JVM 规范中没有明确规定占用多少字节，取决于具体实现。
   - **默认值**：`false`
   - **常用场景**：逻辑判断和条件控制。
   - **示例**：
     ```java
     boolean flag = true;
     ```

## 二、引用数据类型（Reference Types）

**引用类型**在 Java 中包含 **类（class）**、**接口（interface）**、**数组（array）**、以及 **枚举（enum）** 等。与基本数据类型不同，引用类型变量**存储的是对象在堆内存中的引用（地址）**，真正的对象数据存储在堆里。

### 2.1 类（Class）

- **定义**：使用 `class` 关键字定义，是 Java 中的核心结构。
- **实例化**：使用 `new` 关键字创建对象，赋给引用变量。
- **示例**：
  ```java
  // 定义类
  public class Person {
      String name;
      int age;
      public Person(String name, int age) {
          this.name = name;
          this.age = age;
      }
  }

  // 使用
  Person p = new Person("Alice", 20);
  ```

### 2.2 接口（Interface）

- **定义**：使用 `interface` 关键字定义，里面主要包含抽象方法以及默认方法、静态方法等。
- **实现**：类通过 `implements` 关键字来实现接口中的方法。
- **示例**：
  ```java
  public interface Movable {
      void move();
  }

  public class Car implements Movable {
      @Override
      public void move() {
          System.out.println("Car is moving...");
      }
  }
  ```

### 2.3 数组（Array）

- **定义**：数组是一种**定长**的、**同类型**数据的存储结构。既可以是基本类型数组，也可以是对象数组。
- **声明与创建**：
  ```java
  int[] intArray = new int[5];           // 创建 int 类型数组，长度为5
  String[] strArray = new String[3];     // 创建 String 类型数组，长度为3
  int[] another = {1, 2, 3, 4};          // 静态初始化
  ```
- **注意**：数组一旦创建，长度**不可改变**。想要动态调整大小，通常使用集合类（如 `ArrayList`）。

### 2.4 枚举（Enum）

- **定义**：使用 `enum` 关键字定义，可以将一组固定常量集合到一个枚举类型中。
- **常用场景**：状态管理、有限类型集合（如季节、星期等）。
- **示例**：
  ```java
  public enum Season {
      SPRING, SUMMER, AUTUMN, WINTER
  }

  Season s = Season.SPRING;
  ```

## 三、包装类（Wrapper Class）

**包装类**是对基本数据类型的**对象封装**，位于 `java.lang` 包中。每一种基本类型对应一个包装类，例如：

| 基本类型 | 包装类   |
|----------|---------|
| byte     | Byte    |
| short    | Short   |
| int      | Integer |
| long     | Long    |
| float    | Float   |
| double   | Double  |
| char     | Character |
| boolean  | Boolean |

### 3.1 产生背景与作用

1. **面向对象的需求**：在许多场合（如集合框架）需要对象而非基本类型。
2. **提供更多方法**：包装类内部包含了对相应类型的操作方法（如解析字符串为数值、常量属性等）。
3. **支持泛型**：泛型只支持引用类型，不支持基本类型，故需要使用包装类。

### 3.2 自动装箱与拆箱

从 Java 5 开始，引入了**自动装箱（Autoboxing）**和**自动拆箱（Unboxing）**机制，简化基本类型与包装类型之间的转换。

- **自动装箱**：基本类型自动转换为对应的包装类对象。
  ```java
  Integer num = 10;  // 等同于 Integer num = Integer.valueOf(10);
  ```
- **自动拆箱**：包装类对象自动转换为基本类型。
  ```java
  int x = num;       // 等同于 int x = num.intValue();
  ```

### 3.3 常见的包装类方法

1. **parseXxx(String s)**：将字符串转换为对应的基本类型。
   ```java
   int i = Integer.parseInt("123");
   double d = Double.parseDouble("3.14");
   ```
2. **valueOf(String s)**：将字符串转换为**包装类对象**。
   ```java
   Integer num = Integer.valueOf("123");
   ```
3. **xxxValue()**：将包装类对象转换为对应的基本类型。
   ```java
   int val = num.intValue();
   ```
4. **常量**：如 `Integer.MAX_VALUE`、`Integer.MIN_VALUE`、`Double.POSITIVE_INFINITY` 等。

> **注意**：装箱与拆箱过程中可能存在性能损耗，频繁的装/拆箱操作可能影响系统性能。

## 四、常见示例与应用场景

1. **基本类型 vs. 包装类**
   - 计算场景中大量使用基本类型以**提高性能**；
   - 使用集合或泛型时需要包装类。
2. **枚举 vs. 常量**
   - 枚举提供**类型安全**和**可读性**，比常量更具可维护性。
3. **数组 vs. 集合**
   - 数组**长度固定**、可存储基本类型；
   - 集合**动态扩容**，只能存储对象。
4. **泛型中的包装类**
   - 由于泛型不支持基本类型，如 `List<int>` 是非法的，需要使用 `List<Integer>`。

---

## 五、总结

1. **基本数据类型**：占用内存小，效率高，适用于大量计算或简单属性。
2. **引用数据类型**：包括 **类、接口、数组、枚举** 等，需要使用 `new` 或者字面量（对于字符串、枚举）进行初始化，变量存储在栈中，具体对象存储在堆内存中。
3. **包装类**：为基本数据类型提供了对象形态和功能扩展，支持自动装箱与拆箱，可与集合和泛型轻松交互。
4. **选择与使用**：在编程中根据需求和场景，合理选择基本类型或包装类；注重性能和可读性之间的平衡。
